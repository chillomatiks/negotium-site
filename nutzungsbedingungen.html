Geltungsbereich

Diese Bedingungen gelten für „Negotium Upload“, ein internes Werkzeug des YouTube-Kanals Negotium. Es lädt selbst produzierte Videos samt Titel, Beschreibung, Thumbnail und Untertiteln über die YouTube Data API auf den eigenen Kanal hoch.

Nutzung

  • Das Werkzeug wird ausschließlich vom Kanalbetreiber für den eigenen Kanal genutzt. Es gibt keine Registrierung, keine öffentlichen Nutzerkonten und keinen Zugang für Dritte.
  • Hochgeladen werden nur Inhalte, an denen der Kanalbetreiber die erforderlichen Rechte hat.
  • Es werden keine Daten anderer YouTube-Nutzer abgerufen oder verarbeitet.

YouTube

Das Werkzeug nutzt die YouTube API Services. Mit der Nutzung gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Wie Daten verarbeitet werden, steht in der Datenschutzerklärung.
