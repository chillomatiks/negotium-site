Negotium Upload (YouTube API)

„Negotium Upload“ ist ein internes Werkzeug, mit dem der Kanalbetreiber eigene Videos, Titel, Beschreibungen, Thumbnails und Untertitel über die YouTube Data API auf seinen eigenen YouTube-Kanal hochlädt und dort verwaltet.

  • Das Werkzeug wird nur vom Kanalbetreiber mit dessen eigenem Google-Konto verwendet. Es gibt keine weiteren Nutzer.
  • Über die Google-Anmeldung (OAuth) erhält das Werkzeug ein Zugriffstoken für den eigenen Kanal. Dieses Token wird verschlüsselt als Geheimnis im privaten Code-Repository des Betreibers gespeichert und nur für Uploads auf diesen Kanal verwendet.
  • Es werden keine Daten anderer YouTube-Nutzer abgerufen, gespeichert oder weitergegeben – auch keine Kommentare, Abonnenten- oder Zuschauerdaten.
  • Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen.

Das Werkzeug nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.
