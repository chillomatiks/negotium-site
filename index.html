Negotium Upload

„Negotium Upload“ ist ein internes Werkzeug des Kanals. Es lädt selbst produzierte Videos über die YouTube Data API auf den eigenen Kanal hoch. Es wird ausschließlich vom Kanalbetreiber genutzt und verarbeitet keine Daten anderer Personen.
